# Open Source Software Term Project

텀 프로젝트를 위해 사용될 오픈소스는 Javax.Swing 입니다.

현재 개발환경의 Java의 버전은 26으로 Swing의 라이센스는 조건부 무료 라이센스인 NFTC를 따르고 있습니다.

Javax의 Swing은 2세대 GUI API로, 1세대 GUI API인 awt를 승계했다고 할 수 있습니다.
따라서 API에 포함되어있는 구성요소는 awt의 구성요소를 그대로 가져가되, JFrame이나 JDialog와 같은 한 개의 컴포넌트만 OS의 구성요소를 빌려가고 이외의 컴포넌트들은 독자적으로 그래픽 요소를 그리는 형태를 지니고 있습니다.
Swing은 EDT(Event Dispatch Thread)라는 전용 싱글 스레드에서 작업이 처리됩니다. 따라서 현재 보급된 AP(CPU)에 할당된 싱글스레드로는 구현할 수 있는 컴포넌트의 개수는 극히 적습니다.

3세대 GUI API가 존재하고, 성능적으로 제한되어 있음에도 Swing을 선택한 이유는 다음과 같습니다.
- awt의 컴포넌트를 계승하였기 때문에, 코드적 해석이 쉽습니다.
- 별도의 Gradle 시스템 없이 코드 작성자의 마음대로 프로젝트를 구성할 수 있습니다.
- 그럼에도 직접 메모리 할당을 지정해줘야하는 로우 레벨의 커맨드 작성을 요구하지 않습니다.
